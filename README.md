# learning-about-version-control

Solving merge conflicts takes conscious effort, but I can do it!

I like that version control keeps track of changes, allows me to review previous versions, and recover my work if needed.

Version control makes collaboration easier because team members can work on the same project and keep track of each other's contributions.

I find merge conflicts challenging because I need to understand which changes to keep to achieve the best resolution, especially when working on modeling.
